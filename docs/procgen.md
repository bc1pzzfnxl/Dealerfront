# Map & setup (DealerFront)

> Status: **v2** — the map is a **real city** (Paris, IRIS quarters). Procedural grid generation is **abandoned**.

## Objective

Load a **real map** (quarters, zones, profiles) then **set up** the game: faction spawns, neutral quarters, garrisons, police stations. Rendering and logic rely on **mapcn / MapLibre**.

## Rules

### The map is real

- **Paris IRIS**: **992 quarters** INSEE/IGN (`src/sim/maps/paris.ts`, generated by `scripts/build-paris-map.ts`).
- Each quarter carries: a **zone** (derived from the IRIS type), a market **profile** (`demand`, `wealth`) and the list of its **neighbors** (shared edges, not corners).
- Zones serve as **convertible buildings** (`economy.md`): quarters accept certain buildings depending on their zone.
- **Muted basemap**: color carries only faction information (no decorative basemap).

### Game setup

1. **Faction spawns**: 4 spaced positions (greedy sampling over built quarters).
2. **Neutral quarters**: the rest of the city, with **garrisons** (neutrals do not fall for free, cf. `territory.md`).
3. **Police stations**: IRIS zones of type "police" feed **local surveillance** and the anti-leader **Pressure** (`police-ai.md`).

### Readable difficulty

- Difficulty depends on the **number/spread of police stations**, **density**, **wealth** (by arrondissement) and **AI aggressiveness** (`factions.md`).
- It is **visible** on screen (stations, heat, factions) — never a hidden number.

## Edge cases

- **Spawns**: the map ships **4** spawns (farthest-point sampling among built zones) but the game plays **6** cartels. The extras are **derived at runtime** (`World.pickSpawns`) as the built quarters farthest from every spawn already taken — otherwise the extra gangs start with zero quarter.
- **Isolated quarter** (no neighbor): impossible in Paris (adjacency verified: no isolated quarter).
- **City without fronts**: commercial/activity zones provide fronts — hard constraint.
- **Determinism**: the map file is **generated once** and versioned — same build ⇒ same map.
